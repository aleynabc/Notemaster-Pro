# NoteMaster Pro 📝

Google AI Studio ile tasarlanmış modern bir kullanıcı arayüzüne sahip, React Native tabanlı akıllı sipariş yönetimi ve not alma uygulaması; entegre yerel bildirim desteği de bulunmaktadır.

## 🚀 Özellikler

- **Akıllı Sipariş Takibi:** Siparişlerinizi ve müşterilerinizi verimli bir şekilde yönetin.
- **Yerel Bildirimler:** Siparişinizin son teslim tarihinden önce bildirim alın.
- **Modern Kullanıcı Arayüzü:** Yapay zeka desteğiyle tasarlanmış, sade ve kullanıcı dostu arayüz.
- **Android Desteği:** Capacitor aracılığıyla Android cihazlarla tam uyumludur.

## 🛠 Teknoloji Altyapısı

| Katman | Teknoloji |
|---|---|
| Çerçeve (Framework) | React / Vite |
| Mobil Köprü | Capacitor |
| Kullanıcı Arayüzü Tasarımı | Google AI Studio / Tailwind CSS |
| Bildirimler | Capacitor Local Notifications |

## 📦 Kurulum

```bash
npm install
npm run dev
```

Android için detaylı APK oluşturma talimatları için [`BUILD_ANDROID.md`](./BUILD_ANDROID.md) dosyasına bakınız.
